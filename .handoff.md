## Context to Remember

- **EIGHT instrument defects today, and the catch always came from outside the
  head that made the error.** Four were mine: an invented 92.6%, a wrong `ReadAt`
  claim, an unverified "Seek is expensive" claim, and the worst-placed one — the
  error-indistinguishability predicate in shipped `doc.go`, which COULD NOT PASS
  since v0. Two guard checks in one sweep share one `Points`, so arming

  following it would distrust their own correct code.

  caught the flat-invariant defect in the plan in the morning; I rebuilt the
  same defect in the graphdb harness that afternoon.
- **`go-mutesting` mutates source files IN PLACE.** Never run the mutation gate
  concurrently with anything else in the same tree.

  pointed at their working checkout, which was sitting on the fix branch. It
  compared the fix against the fix and reported zero.
