## What the plan is, in one paragraph

`sweep.go:80` yields K+1 passes for a K-operation scenario: one failing each
operation in turn, plus a terminating pass that fails none. DO-178C 6.4.2.2 calls
those robustness and normal range. **A sweep produces both in one loop and
nothing separates them afterwards**, so a coupling site touched only by the
terminating pass reports as covered while its error path has never executed. That
is this repository's own false-green class, moved from inside a component to the
interface between two.
