## Context to Remember

- **`fs.New` and `fs.NewShortWrite` now return `*fs.Fault`, not `FS`.** That is
  a breaking change and LARGER than it looks: a function VALUE of `New` is no
  longer assignable to one returning `FS`, because Go has no covariance in a
  result type. This repository's own `shortwrite_test.go` did exactly that.
  Anyone comparing the two constructors in a table hits it.
- **NINE instrument defects today, and the catch always came from outside the
  head that made the error.** Mine included an invented 92.6%, a wrong `ReadAt`
  claim, an unverified "Seek is expensive" claim, a "source-compatible in
  practice" claim that was not, and the worst-placed: a predicate in shipped
  `doc.go` that could not pass.
- **Naming a failure mode does not inoculate you against it.** An implementer
  caught the flat-invariant defect in the plan in the morning; the same defect
  was rebuilt in the graphdb harness that afternoon.
- **`go-mutesting` mutates source files IN PLACE.** Never run the mutation gate
  concurrently with anything else in the same tree.
- **Name the artifact in the verdict line.** A "control" run pointed at
  graphdb's working checkout, which sat on the fix branch, and compared the fix
  against the fix.
- **Check the STE rule set before publishing, not in the same command.** Three
  PR bodies published with violations because the check and the publish ran
  together, which is not checking.
